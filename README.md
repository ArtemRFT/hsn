# ХСН — квартальный отчёт

Веб-приложение на Streamlit: загружаете выгрузку «Детализация» — получаете
готовый xlsx-отчёт с очищенными данными (убраны дубли по СНИЛС и пациенты
с датой смерти) и сводными таблицами с диаграммами.

## Структура проекта

```
hsn-quarterly-report/
├── app.py            # интерфейс Streamlit
├── hsn_report.py      # вся логика очистки данных и сборки xlsx (без Streamlit)
├── requirements.txt
└── .gitignore
```

`hsn_report.py` не зависит от Streamlit, поэтому его можно тестировать
и переиспользовать отдельно (например, из обычного Python-скрипта).

## Локальный запуск (проверить перед деплоем)

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Откроется браузер на `http://localhost:8501`.

## Деплой: GitHub + Streamlit Community Cloud

### 1. Выложить код на GitHub

```bash
cd hsn-quarterly-report
git init
git add .
git commit -m "Первая версия отчёта ХСН"
```

Дальше на github.com:
1. Создайте новый **пустой** репозиторий (без README/лицензии — они уже есть локально), например `hsn-quarterly-report`.
2. Свяжите и запушьте:

```bash
git branch -M main
git remote add origin https://github.com/<ваш-логин>/hsn-quarterly-report.git
git push -u origin main
```

### 2. Деплой на Streamlit Community Cloud (бесплатно)

1. Зайдите на **share.streamlit.io** и войдите через GitHub-аккаунт.
2. Нажмите **New app**.
3. Выберите репозиторий `hsn-quarterly-report`, ветку `main`, файл `app.py`.
4. Нажмите **Deploy**.

Через пару минут приложение будет доступно по постоянной ссылке вида
`https://<app-name>.streamlit.app` — заходите туда каждый квартал,
загружаете новый файл, скачиваете готовый отчёт. GitHub и Streamlit
Cloud бесплатны для такого использования.

### Обновление в будущем

Если понадобится что-то поправить в логике — меняете `hsn_report.py`
или `app.py`, коммитите и пушите:

```bash
git add .
git commit -m "Правки"
git push
```

Streamlit Cloud подхватит изменения из GitHub автоматически и
переразвернёт приложение за 1–2 минуты.

## Если формат выгрузки поменяется

Логика ожидает:
- лист, в названии которого есть «Детализ» (по умолчанию «Детализация»);
- строку заголовков с столбцом **«СНИЛС»** где-то в первых 6 строках листа
  (сам её находит — неважно, на первой она строке или сдвинута);
- столбцы **«СНИЛС»** и **«Дата смерти»** (обязательны);
- для сводных таблиц: «Группа инвалидности», «Код федеральной льготы»,
  «Код региональной льготы», «Стадия ХСН», «Функциональный класс ХСН»,
  «Вид ХСН по ФВ ЛЖ» (если какого-то столбца нет — на его листе просто
  будет написано «Нет данных»).

Если названия столбцов изменятся — поправьте константы `PIVOT_COLS` и
`SHEET_NAME_MAP` в начале `hsn_report.py`.
